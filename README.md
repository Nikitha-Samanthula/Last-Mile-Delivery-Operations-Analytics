# Last Mile Delivery Operations Analytics

📌 Project Overview
-------------------------------------------------------------------------------------------------
An end-to-end Power BI project focused on analyzing last-mile delivery operations to understand delivery demand, customer behavior, delivery performance, driver and vehicle utilization, and delivery issues.
The data was cleaned and transformed using Power Query and presented through interactive Power BI dashboards.

🛠️ Tools & Technologies
----------------------------------------------------------------------------------------------------------------------------------------
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

🔄 Data Preparation & Transformation
----------------------------------------------------------------------------------------------------------------------------------------------

- Cleaned and standardized data using Power Query
- Handled missing values, inconsistent text, and duplicate records
- Corrected data types for accurate analysis
- Validated data quality by trimming and cleaning text
- Built relationships between Customers, Orders, Deliveries, Drivers, Vehicles, and Date tables

📊 Dashboard Pages
---------------------------------------------------------------------------------------------------------------------------------------------

- Delivery Demand Analysis – Analyzes orders by zone, service type, priority, and time.
- Customer Order Behaviour – Analyzes customer activity, order value, and customer segments.
- Delivery Performance – Analyzes delivery status, duration, and delivery outcomes.
- Driver & Vehicle Performance – Analyzes driver activity, delivery outcomes, and vehicle utilization.
- Delivery Problem Analysis – Analyzes failed deliveries, multiple attempts, and problem patterns.
- Executive Summary – Provides a high-level overview of key KPIs and business insights.

🎯 Project Objective
----------------------------------------------------------------------------------------------------------------------------------------------

To transform raw delivery data into meaningful business insights that support operational efficiency, resource utilization, and data-driven decision-making.

📚 Key Learnings
----------------------------------------------------------------------------------------------------------------------------------------------

- 3K total orders across multiple delivery zones.
- Total order value: 7.52M
- Average order value: 2.51K
- Delivery success rate: 73.74%
- Average delivery duration: 47.19
- Average delivery attempts: 1.05
- Order volume shows a declining trend across the displayed months.
- Delivery success rates vary across zones, ranging from approximately 68% to 79%.
